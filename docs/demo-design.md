# Painel de demonstração

Direção: painel de trabalho familiar, com leitura rápida, sem identidade visual final definida. Referências online Refero indisponíveis por assinatura; referências locais consultadas: Color Guide (neutros, contraste e cores semânticas para dados), Typography Guide (hierarquia simples e tipografia neutra) e Craft Details (foco, labels e formulários).

Decisões: superfícies claras, texto escuro, verde para saldo/receitas, areia para despesas, cartões de resumo acima dos gráficos, tabela filtrável e banner explícito de demonstração. Os gráficos são gerados a partir das movimentações e têm descrição textual acessível. Não há necessidade de imagens decorativas.

Teste visual em 29/10/2026: painel aberto na sessão real do administrador no navegador integrado ao VS Code. Verificados apresentação de totais e gráficos, inclusão e exclusão de uma despesa, limpeza completa, estado vazio e restauração dos exemplos. A interface usa breakpoints para celular; a inspeção visual específica em um dispositivo móvel não foi realizada.
